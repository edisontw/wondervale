# E09 — The Closed Hill (isolated browser authoring lab)

Run from repository root with `python3 -m http.server 4173`, then open `http://127.0.0.1:4173/e09-prototype/`.

This is a **fictional five-node safe survey model**, not a production episode, real public access map, slope safety certificate or historical record. Child-controlled Milo can walk adjacent safe edges, inspect a fixed fence and ground clues, try a closed direction without crossing, revise marks on surveyed edges, check computed route continuity, compare a distant unidentified symbol shape and separate seen/think/unknown evidence. Reset and reload discard everything. No canonical Chronicle, E10 unlock, persistent save, tracking or production art.

Node engine tests: `node --test tests/s01e09-authoring-prototype.test.mjs`.
Chromium tests: `node tests/s01e09-browser.mjs` after installing pinned Playwright and starting the HTTP server. CI exercises four viewport sizes and keyboard actions. Browser checks are not real-device/Owner acceptance.

The approved E01/E02/C01 and E03 runtime/art are not imported or modified. Real hill geometry, legal public access, terrain safety, source cards and final painterly art remain Owner-gated. Never deploy this lab to MN4 as a playable episode.
