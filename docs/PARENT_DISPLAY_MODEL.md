# Parent guidance model (updated 2026-10-12)

The owner explicitly **removed the dedicated Parent View** in E01. The old desktop sidebar (70–75%/25–30%) and phone Child/Parent toggle are **superseded**.

The initial chapter briefing shows **all existing parent content once before Begin**: the preview, one discussion cue, follow-up, fallback, and reflection. Parents can read this together with the child. Required opening dialogue cannot be skipped. After Begin, gameplay contains no parent panel.

Settings and support are still available from **Options** (synthetic read-aloud, reduced movement, motor assistance and confirmation-gated progress reset). These are not live teaching notes. Children control Milo and complete the entire episode without switching views.

Phone landscape is the primary responsive layout, with Square and RPG dialogue in two columns. Portrait is a usable fallback; do not force or lock orientation. Both phones and desktop fit the window and preserve the entire painted Town Square at its original aspect ratio. Optional native browser fullscreen is user initiated when supported, with a non-blocking fallback when unavailable.

Preserve the EFL/parent-guided intent, approved E01 script and original art. New episodes can reuse this chapter-briefing presentation, but this slice does not change E02.

See [E01 landscape/fullscreen revision](E01_FULLSCREEN_LANDSCAPE_2026-10-12.md) for tests and deployment notes. Previous design rationale survives in Git history.
