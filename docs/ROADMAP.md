# Roadmap

## Phase 0 — Foundation

- product vision
- world continuity rules
- learning framework
- parent guidance system
- content schema
- architecture
- deployment baseline

Exit condition: the team can author one episode without inventing new structural rules.

## Phase 1 — Application shell

- responsive application
- story scene runtime
- basic navigation
- parent cue UI
- local progress
- accessibility baseline
- content validation

Exit condition: a placeholder episode can run end-to-end entirely from structured content.

## Phase 2 — Episode 01 vertical slice

Build one real Season 1 episode, not a disposable demo.

Must include:

- recurring characters;
- story hook;
- exploration;
- at least one substantive interactive activity;
- parent-guided discussion;
- visible consequence;
- structured learning metadata;
- structured continuity state.

Exit condition: a parent and child can complete the episode without developer explanation.

## Phase 3 — MVP

Expand to 3–4 connected episodes.

Test:

- whether families return;
- whether characters are memorable;
- whether parent cues create conversation;
- whether reused activity primitives feel repetitive;
- whether continuity is noticed.

## Phase 4 — Season 1 alpha

Target roughly 10–12 coherent episodes.

Add:

- callbacks;
- visible world changes;
- character development;
- skill revisit/transfer;
- more varied activities;
- richer accessibility and audio.

## Phase 5 — Usage-driven expansion

Only after meaningful usage, evaluate:

- cloud accounts;
- child profiles;
- adaptive challenge;
- authoring CMS;
- multilingual versions;
- dedicated hosting;
- richer telemetry with privacy safeguards.

Do not build these merely because they are technically possible.
