## Implementation contract

- Keep `e02/` isolated; no changes to `app/`, `engine/episode.mjs` (E01) or shared media assets.
- A light `.world-frame` centers the *entire* 1672:941 Riverside illustration within the available flex area; never crop the river, closed spur, safe public ramp or trio. Only mobile CSS changes that presentation.
- In normal phone free-roam, a placeholder `Choose what Milo does next` is hidden; authentic queued dialogue must remain as an RPG caption with speaker, current exact line, Continue and manual Listen.
- For short **landscape ≤760 CSS width and ≤420 CSS height**, the app header floats at the top scene edge, but still exposes the Wondervale link and **Child / Parent View** 44px hit targets. Decorative headline does not reserve height. Explicit walking buttons form one horizontal, self-scrollable 44px-high row **below the art**; hotspots in the scene remain reachable. Status stays as a compact contained strip.
- The actual story caption appears below the scene and is bounded, with its long text scrollable internally rather than cropping navigation or the whole game. Avoid full-document scroll for ordinary short-landscape exploration.
- For mobile portrait, keep a width-fitted complete image; a long game or story page may scroll inside the child panel as needed.
- Parent mode on phones is a separate accessible content view; it no longer appends prompts below an offscreen gameplay panel. Notebook, Chronicle, revision and other long content stay internally scrollable and must not lose their fact/answer buttons.
- CSS viewport sizes, **not iPhone screenshot physical pixel counts**, define the regression matrices. Simulated Chromium touch tests cannot replace owner WebKit acceptance.
- E02 build `20261014-e02-mobile-shell1` versions this UI layer without changing the E02 script or stable `e01Ready` prerequisite.
