# Content Strategy

## Purpose

Wondervale needs a content system that can stay coherent, surprising, and educational after dozens or hundreds of episodes.

The main risk is not a lack of activities. It is becoming a worksheet library wrapped in recurring art.

## Narrative hierarchy

Use the following planning hierarchy:

```
World
└── Season
    └── Story Arc
        └── Episode
            └── Scene
                └── Beat / Activity
```

A **Story Arc** usually spans 3–5 episodes and provides the medium-term unit for setup, development, payoff, and learning revisit.

## Content types

### Core Episode
Advances the main season story and canonical timeline.

### Side Story
Optional character/world story. May deepen relationships or revisit skills but should not create a major prerequisite for the main path.

### Free Explore
A location-based experience that supports discovery, practice, and world familiarity without requiring a full narrative episode.

### Special / Seasonal Story
Time-limited in theme, not necessarily in availability. Avoid making important learning inaccessible because a calendar event expired.

The MVP should focus on Core Episodes. Other types are expansion paths, not launch requirements.

## Episode design budget

A normal Core Episode should usually contain:

- one clear story problem;
- one or two primary learning goals;
- a small number of secondary/revisit goals;
- one meaningful parent-child discussion moment;
- one or two substantial interactions;
- one visible story/world consequence;
- one reason to wonder what happens next.

Do not require every episode to include English, mathematics, science, and humanities.

Some episodes may deliberately emphasize:

- character relationships;
- exploration;
- humor;
- mystery;
- building;
- observation;
- storytelling.

These quieter episodes protect pacing and prevent the world from feeling like a curriculum conveyor belt.

## Variety model

Track two different dimensions.

### Cognitive action
What the child is thinking:

- observe
- notice patterns
- compare
- estimate
- infer
- predict
- classify
- plan
- model
- test
- revise
- explain
- negotiate
- create
- tell / retell
- take another perspective

### Interaction mechanic
What the child is doing with the interface:

- tap / inspect
- drag
- sort
- sequence
- build
- simulate
- map
- listen
- speak with parent
- choose
- draw / arrange
- measure
- search

Avoid confusing a new interface mechanic with a new kind of thinking.

A content review should flag long runs of episodes that repeat either the same cognitive action or the same visible mechanic.

## Learning continuity

Each important concept should have opportunities for:

**Encounter → Explore → Apply → Revisit → Transfer → Deepen**

Revisit does not mean repeating the original task with different numbers or pictures.

A useful revisit changes context, representation, or purpose.

## Narrative continuity

Track:

- promises made to the audience;
- unresolved mysteries;
- character goals;
- relationship changes;
- location changes;
- objects with future significance;
- prior failures and successes worth recalling;
- learning concepts that can become future tools.

Callbacks should reward memory without making a child unable to continue after a long absence.

## Return after absence

Episodes should support a lightweight recap generated from completed canonical events:

- what just happened;
- who matters now;
- what problem remains.

A child returning after weeks should not need to replay the season from the beginning.

## Choice policy

Avoid uncontrolled branching in early versions.

Use choices for:

- strategy;
- order of exploration;
- dialogue flavor;
- optional discoveries;
- local consequences.

Major canonical forks multiply writing, testing, continuity, and learning requirements. Add them only intentionally.

## Surprise without randomness

Variety should come from story, perspective, environment, and thinking—not from arbitrary reward randomness.

Avoid systems that depend on:

- loot boxes;
- gacha;
- streak pressure;
- fear of missing out;
- random rewards as the main reason to return.

## Content review questions

Before an episode is accepted:

1. Why does the child care about the problem?
2. What new or deepened thinking occurs?
3. What does the child actually do?
4. What can the parent contribute without teaching the answer?
5. What changes because this episode happened?
6. What earlier idea is reused?
7. What future idea can this episode prepare?
8. Does this feel meaningfully different from the previous few episodes?
9. Is the story still enjoyable if the learning labels are hidden?
10. Is the learning still meaningful if the decorative rewards are removed?
